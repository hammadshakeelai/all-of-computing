## Choose one measurable outcome

Write: “I want to be able to ___, using ___, and demonstrate it by ___.”

Examples: implement and explain binary search with edge-case tests; derive a gradient for linear regression; compare classification metrics on an imbalanced dataset without data leakage. These are candidate tasks, not an assigned level or an exhaustive curriculum.

Record the trusted reference, why the outcome matters to your degree, prerequisites, and a manageable artifact. Link other interesting topics into a backlog rather than activating them all.

## Diagnostic sample

| Area | Candidate task | What to inspect |
| --- | --- | --- |
| Programming | Trace then repair a short program with a faulty boundary condition | Execution reasoning, tests, explanation |
| Algorithms | Compare two search strategies on a new example | Assumptions, correctness, complexity |
| Discrete math | Explain an implication and test a counterexample | Logical precision and reasoning |
| Linear algebra | Work a small matrix/vector operation and explain shapes | Calculation and interpretation |
| Probability | Explain conditional probability with a numerical example | Distinguishing joint and conditional events |
| ML evaluation | Identify leakage in a proposed train/test workflow | Valid evaluation reasoning |

The app does not contain an automated placement bank. Create or obtain reviewed questions and add the relevant concepts manually. Attempt without notes first; disclose help. Check against an appropriate reference, and retain uncertainty when a rubric is ambiguous. Adapt tasks if prerequisites are absent.

## Evidence journal

For each attempt record: concept and objective, question, original answer, date, source/rubric version, hints or outside help, feedback origin, corrections or disputes, and a next task. For projects, link the artifact and results from private notes; the app does not execute submitted code.

## End-of-pilot decision

- What can I now explain or do on a fresh task?
- Which missing prerequisite actually blocked me?
- Was planning and recording easier than my previous approach?
- Which feedback judgments were questionable?
- What should stay active, be paused, or enter the backlog?

Choose the next objective using these answers. Do not turn a few quiz results into a global claim about your ability. [Scope and pilot](SCOPE.md).
